# TP0_ICT_207_CHENANGE_24H2254

Ce depot contient les exercices du Support_3_Bases_de_la_POO_Java pour la matiere ICT 207.

## Fichiers
- `exo_diapo_22.java` : premier exercice qui consitait a :
    
1. Modifier le constructeur Point (double a, double b) en Point
   (double x, double y).
2. Ajouter un constructeur permettant de creer un point par copie
d'un autre point donne.
3. Ajouter une methode afficher permettant d'afficher les
coordonnees du point.
4. Ajouter une methode distance permettant de calculer la distance
entre le point actuel et un autre point donne.
5. Ecrire une classe TestPoint contenant un main permettant de
tester tous les constructeurs et toutes les methodes de la classe
Point


- `exo_diapo_34.java` : deuxieme exercice qui consistait a:
Ecrire le code d'une classe Division qui offre deux
methodes diviser()
1. La premiere est une methode d'instance
2. La deuxieme est une methode de classe
Ecrire le code d'une classe Division qui offre deux
methodes diviser()


- `exo_diapo_34i.java` : troisieme  exercice qui consistait a:
   Ecrire le code d'une classe TestDivision qui permet de
tester les deux methodes diviser. Laquelle est meilleure
dans ce cas?

## Instructions
1. Cloner le depot
2. Ouvrir les fichiers avec votre editeur
